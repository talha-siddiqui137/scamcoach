# ScamCoach 🛡️

**Team:** <Name 1>, <Name 2>  |  **Event:** Build4Better – Codesphere 3.0, NED University

## Target user and problem
Parents and grandparents who get fake bank, prize and "new number" messages. They are scared to click, or they get tricked. They usually call their children for help.

## Solution and core features
ScamCoach **teaches** instead of just blocking:
1. **Check a message** – paste a message; it shows red flags, *why* each matters, and *what to do*.
2. **Practice** – a 6-question "real or scam?" game with a plain explanation after each answer.
3. **5 Simple Rules** – big-text safety rules to remember.
Large text, big buttons, plain words.

## Setup and run
```
pip install -r requirements.txt
streamlit run app.py
```

## Tech stack
Python, Streamlit. Rule-based checker (regex), no external API.

## Known limitations / mocked features
- Checker is rule-based, not a real AI; it can miss new scams or flag safe messages.
- English only; messages are not stored or sent anywhere.
